# Credits

## Piano
Salamander Grand Piano by Alexander Holm, licensed [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). It is the same sample set used in [Melody Writer](https://github.com/rjbrown85/melody-writer), originally from the [Tone.js audio repository](https://github.com/Tonejs/audio/tree/master/salamander). Twenty-three notes (F#1 to C7, every minor third) are trimmed and built into `index.html`, so the piano plays even when the file is opened offline. Source: [SFZ Instruments](https://sfzinstruments.github.io/pianos/salamander/).

Each feeling plays a short piano piece written as MIDI note data (note numbers, start times, lengths, and velocities in `index.html`) and voiced with these samples. The button click is a short, soft tap on the same piano. No synthesized sounds are used.

## Feelings
The 30 feelings follow the classroom Show, Don't Tell emotion chart set. Only the feeling names are used; the chart's own example lists are not reproduced here.

## Similes, metaphors, and translations
Common English similes and metaphors, with kid-friendly meanings, collected for Grade 5. Swedish, Simplified Chinese, and Korean translations were drafted with AI help (Claude) and should be checked by native speakers.
